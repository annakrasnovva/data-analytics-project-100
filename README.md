
## 📊 Анализ конверсии сайта с помощью Python

### О проекте

Учебный проект Hexlet, выполненный с использованием Python и инструментов анализа и визуализации данных.

**Цель:** исследовать посещаемость сайта, динамику регистраций и конверсию пользователей с учётом платформ и рекламной активности.

### 🛠 Стек технологий

- **Python**
- **Pandas, NumPy** — обработка и анализ данных
- **Matplotlib, Seaborn** — визуализация
- **Requests** — получение данных из API
- **Jupyter Notebook** — проведение исследования
- **CSV / JSON** — работа с данными

### Выполненная работа

- Получила данные о посещениях и регистрациях из учебного API.
- Выполнила обработку и агрегирование данных по датам и платформам.
- Рассчитала показатели посещаемости, регистраций и конверсии.
- Исследовала различия в динамике показателей по платформам.
- Сопоставила пользовательскую активность с рекламными расходами.
- Построила графики и подготовила презентацию с результатами анализа.

### 📈 Результаты исследования

По результатам первоначального анализа:

- **12 марта 2023 года** зафиксирован пик посещаемости — **1 394 посещения**.
- **6 марта 2023 года** зафиксирован максимум регистраций — **230**.
- Обнаружены различия в конверсии пользователей между платформами.
- Исследована динамика рекламной активности и пользовательских показателей.

> **Примечание:** методика расчёта конверсий требует дополнительной проверки, включая обработку дней без регистраций. Представленные значения отражают первоначальные результаты проекта.

### 🚀 Запуск проекта

Для локального запуска потребуются Python, Jupyter Notebook и библиотеки:

- pandas
- numpy
- matplotlib
- seaborn
- requests
- python-dotenv

Ноутбук использует переменные окружения `API_URL`, `DATE_BEGIN`, `DATE_END` и доступ к учебному API.

После настройки окружения необходимо создать каталог `charts` и последовательно выполнить ячейки ноутбука.

### ⚠️ Ограничения анализа

- Учебный API может быть недоступен вне образовательной среды.
- Необходимо перепроверить объединение данных о посещениях и регистрациях, включая группы с нулевым количеством регистраций.
- Для расчёта общей конверсии за период следует учитывать суммарные посещения и регистрации, а не только среднее дневных процентов.
- Наличие связи между рекламными расходами и регистрациями не доказывает причинного влияния рекламы.
